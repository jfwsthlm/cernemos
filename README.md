# Overview
This is a Java-based project that provides tools for encrypting and decrypting messages using various classical cipher methods. The project is designed to be both an educational resource for understanding basic cryptography and a practical tool for text manipulation.

# Features
## Implemented Ciphers:

* Substitution Cipher: Supports encryption and decryption with replacement with the help of a key.
* ROT13 Cipher: Supports encryption and decryption using replacement of a letter with the 13th letter after it in the Latin alphabet.

## Analysis Tools:

Frequency Analysis: Tool for analyzing the letter frequency in an encrypted text to assist in cracking (e.g., for Caesar and substitution ciphers).

## Usability:

Modular Design: The code is structured with separate classes for each cipher, making it easy to add new methods.

# Technologies
* Language: Java
* Build Tool: Maven

# Getting Started
## Prerequisites
You need the Java Development Kit (JDK) installed on your system.

## Building the Project
Clone the repository and build the project using your chosen build tool:

## Clone the repository
    git clone https://github.com/jfwsthlm/cernemos.git

## Build with Maven
    mvn clean install
